# Greedy Adventures - Sea View prototype

Next.js / TypeScript experience page with assistant-ui chat and a backend-connected knowledge view.

## Local setup

Use Node.js 22.17+ (or Node 24). Run `npm ci`, then `npm run dev`. Open http://localhost:3000. Production: `npm run build` then `npm start`.

## Current status

**MOCK MODE ONLY. No LLM is connected. This does not yet satisfy the assignment's working AI backend requirement.** No API key or paid model is used. Confirm model access with the founder before spending money. The chat uses deterministic backend rules and keeps history only in the current browser session. It supports a bounded set of questions, not general language understanding. Reloading clears history.

## Sources and media

Public source: https://www.greedyadventures.com/experiences/sea-view-skydiving captured 30 October 2026. Curated excerpts and structured package data live in `src/lib/knowledge.ts`. Prices and availability must be reconfirmed with the operator. Photography and video belong to the source website and are referenced remotely for this assignment. External media availability depends on its host.

The PDF is generated by `/api/brochure` using pdf-lib and clearly labelled demo material. The video is a public MP4 linked from the supplied experience page. No real booking, payments, authentication, database or crawler is implemented.

## Flow and knowledge view

assistant-ui LocalRuntime sends conversation messages to `/api/chat`. Zod validates inputs. `src/lib/chat.ts` selects source passages, produces a mock answer and selects allowed media from the registry. React renders text safely without HTML injection. No secrets or private conversations are persisted or exposed.

Open `/knowledge` from the navigation or chat. `/api/knowledge` returns the real source registry. Running a test question calls the same `/api/chat` endpoint used by chat and displays its actual response and trace. In mock mode the trace explicitly says no model was called. The failure checkbox returns a deliberate 503 to verify error handling. It does not expose other visitors' questions.

## Verification

Run `npm test`, `npm run typecheck` and `npm run build`.

- Ask what the package includes. Expect text and a source link without attachments.
- Ask about DELUXE then ask how much it costs. Expect THB 12,500.
- Ask for a brochure, a video, and both. Expect the corresponding open/download links. Open each file.
- Ask for insurance documentation or a weight limit. Expect an unavailable answer without invented files or policies.
- In the knowledge view run a question and inspect selected passages and media. Toggle failure simulation and expect a clear error.
- Test mobile/desktop layouts and keyboard access. Escape closes the guide and returns focus to its launcher.
